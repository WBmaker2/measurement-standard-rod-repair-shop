# 측정 기준봉 정비소 기능·디자인 개선 기록

**작성일:** 2026-07-17  
**기준 문서:** `2026-07-17-measurement-standard-rod-repair-shop-mvp.md`  
**구현 방향:** 따뜻한 목공 작업대 시안

## 1. 분석 요약

기존 MVP 계획은 측정 개념, 오개념 방지, 미션 데이터, 접근성 기준이 매우 구체적입니다. 다만 실제 저학년 학생이 한 화면에서 무엇을 먼저 보고 어떤 버튼을 눌러야 하는지, 수리 후 무엇이 달라졌는지 즉시 비교하는 방법, 작은 화면에서 긴 절차를 놓치지 않는 방법은 구현 단계에서 더 분명하게 정리할 필요가 있습니다.

이번 구현은 모든 계획 항목을 한 번에 노출하지 않고 `어림하기 → 고장 찾기 → 수리하기 → 다시 재기 → 이유 고르기`의 다섯 단계로 압축합니다. 각 단계에서는 현재 해야 할 행동 하나만 강조하고, 완료된 행동은 작은 진행 표시로 남깁니다.

## 2. 기능상 개선점

### F-01. 한 번에 한 행동만 보이는 미션 흐름

- 문제: 8단계 학습 순환을 한 화면에 모두 보여 주면 초등 1~2학년에게 선택 부담이 큽니다.
- 개선: 학생 화면에서는 다섯 단계로 묶고 현재 단계에 필요한 선택지만 활성화합니다.
- 완료 기준: 다음 단계로 넘어가기 전 필요한 선택이 분명하며, 잘못 고른 경우 다음에 살펴볼 곳을 한 문장으로 안내합니다.

### F-02. 수리 전후를 같은 자리에서 비교

- 문제: 화면이 바뀌면 고장난 기준봉의 모양과 잘못 표시된 값을 기억하기 어렵습니다.
- 개선: 작업대 위 기준봉이 같은 위치에서 부드럽게 정비되고, 옆의 비교표에는 `정비 전 표시`와 `바른 측정`을 함께 남깁니다.
- 완료 기준: 물체 길이는 그대로이고 도구의 배치만 바뀌었다는 점을 학생이 즉시 확인할 수 있습니다.

### F-03. 모든 미션에 결정적인 수리 동작 제공

- 문제: 자유 드래그는 정밀 조작 능력이 학습 결과에 영향을 줍니다.
- 개선: `0에 맞추기`, `틈 닫기`, `겹침 풀기`, `같은 크기로 맞추기`, `눈금 사이 세기` 버튼만 사용합니다.
- 완료 기준: 키보드와 터치만으로 튜토리얼 및 미션 5개를 모두 완료할 수 있습니다.

### F-04. 되돌리기와 처음부터 다시 하기

- 문제: 잘못 누른 뒤 전체 미션을 잃으면 실험하기를 꺼릴 수 있습니다.
- 개선: 한 단계 되돌리기를 제공하고, 전체 초기화는 확인 대화상자를 거칩니다.
- 완료 기준: 되돌리면 뒤 단계의 측정·이유 선택이 함께 안전하게 초기화됩니다.

### F-05. 점수 대신 측정 정비 기록

- 문제: 점수와 속도는 측정 원리 설명보다 정답 맞히기에 집중하게 합니다.
- 개선: 각 미션 완료 시 `무엇이 고장났나요 / 어떻게 고쳤나요 / 왜 달라졌나요`를 기록합니다.
- 완료 기준: 완료 화면에서 미션별 기록을 읽을 수 있고 실패 횟수나 시간은 표시하지 않습니다.

### F-06. 선택형 보조 학습 분리

- 문제: `1m = 100cm` 관계까지 핵심 미션에 넣으면 길이 측정 오류 수리라는 중심 경험이 흐려집니다.
- 개선: 1m 관계와 교사용 안내는 헤더의 보조 버튼으로 분리하고, 미션 진행 상태를 잃지 않게 대화상자로 엽니다.
- 완료 기준: 보조 자료를 보거나 닫아도 현재 미션과 선택이 유지됩니다.

## 3. 디자인·UI 개선점

### D-01. 따뜻하지만 학습 요소가 먼저 보이는 작업대

- 크림 배경, 밝은 목재 작업대, 청록색 주요 버튼, 호박색 강조를 사용합니다.
- 장식은 나뭇결과 작은 공구 라벨 정도로 제한하고, 기준봉과 물체가 첫 시선의 중심이 되게 합니다.
- 모든 카드에 같은 큰 둥근 모서리를 반복하지 않고 작업대, 안내 카드, 작은 기록 카드의 반경을 구분합니다.

### D-02. 시선 순서를 고정하는 2열 구조

- 넓은 화면: 왼쪽에 현재 단계와 짧은 안내, 오른쪽에 작업대와 조작 도구를 둡니다.
- 작은 화면: 미션 안내 → 작업대 → 선택 버튼 순으로 재배치하고 하단에 현재 측정 요약을 붙입니다.
- 본문 폭을 제한해 한 문장이 너무 길어지지 않게 합니다.

### D-03. 색 이외의 고장 표시

- 틈은 실제 빈 공간과 `틈` 꼬리표, 겹침은 사선 무늬와 `겹침` 꼬리표, 다른 크기는 너비 차이와 `크기 다름` 글자로 함께 표시합니다.
- 선택된 단위칸은 색, 굵은 외곽선, 무늬를 함께 사용합니다.

### D-04. 44px 이상 조작과 분명한 상태

- 모든 버튼은 최소 높이 48px을 사용합니다.
- hover, 눌림, 키보드 focus-visible, 비활성 상태를 각각 구분합니다.
- 주 행동 버튼은 단계마다 하나만 강하게 표시합니다.

### D-05. SVG와 동등한 텍스트 설명

- 기준봉 시각화 아래에 `물체 시작 0, 끝 5, 같은 칸 5개` 형식의 텍스트 단위표를 제공합니다.
- 상태가 바뀌면 `aria-live`로 수리 결과를 읽어 줍니다.
- 화면 확대와 관계없이 정수 모형 좌표로 결과를 계산합니다.

### D-06. 저학년용 문장 다듬기

- 한 문장을 가능한 한 짧게 쓰고, 버튼은 동사형으로 씁니다.
- `오답`이나 `틀렸어요` 대신 `다시 살펴볼 곳`과 구체적인 다음 행동을 안내합니다.
- 화면 속 칸이 실제 1cm가 아니라는 안내를 시작 화면과 작업대에 반복합니다.

## 4. 구현 범위

- 튜토리얼 1개와 오류 미션 5개
- 시작점, 틈, 겹침, 서로 다른 단위 크기, 눈금선/구간 혼동
- 어림, 오류 선택, 수리, 다시 세기, 이유 선택
- 미션 기록, 1m 관계 카드, 교사용 안내, 업데이트 내역
- 반응형 화면, 키보드 조작, 움직임 감소, 텍스트 대체 설명
- 서버·로그인·저장·추적 없는 정적 앱

## 5. 검증 기준

- 각 미션의 고장 유형과 허용 수리가 데이터와 일치합니다.
- 수리 후 측정값은 물체의 정수 모형 길이와 일치합니다.
- 눈금선 수와 단위 구간 수를 구분합니다.
- 320px 화면과 200% 확대에서 가로 스크롤 없이 핵심 흐름을 완료할 수 있습니다.
- 키보드만으로 모든 선택과 대화상자 열기·닫기를 수행할 수 있습니다.
- 모든 코드 파일은 500줄 미만을 유지합니다.
- 앱 안 `업데이트 내역`에 2026-07-17 최초 구현 및 이번 개선 내용을 기록합니다.
- 소셜 공유 카드와 제목 글자 무게를 보완해, 공유 화면과 저학년용 첫 화면의 시각 위계를 더 또렷하게 합니다.

## 6. 구현 반영 기록

**반영일:** 2026-07-17  
**버전:** v1.0.1

- 안내 활동 뒤에 `어림 → 고장 찾기 → 수리 → 다시 세기 → 값 확인 → 이유 고르기` 순서로 한 번에 한 행동만 보이게 구현했습니다.
- 시작점, 틈, 겹침, 서로 다른 단위 크기, 겹침과 눈금 숫자가 함께 고장난 마지막 미션까지 고정 데이터로 분리했습니다.
- 정비 전 표시와 바른 측정값을 같은 작업대 아래에서 비교하고, 각 기준봉에 텍스트 대체 설명을 붙였습니다.
- 한 단계 되돌리기, 확인 뒤 처음부터 다시 하기, 1m 관계 카드, 교사용 안내, 측정 정비 기록과 업데이트 내역을 추가했습니다.
- 320px 대응 단일 열, 48px 이상 버튼, 키보드 초점, 상태 알림(`aria-live`), 움직임 줄이기 설정을 반영했습니다.
- 콘텐츠 규칙 테스트와 서버 렌더링 테스트를 추가해 미션 값·복합 수리·첫 화면 안내를 검증했습니다.
